## Slide 10: Future Scope
**Title:** Future Roadmap & Enhancements

*   **Cloud Integration:** Implement real-time log uploading to a secure cloud server (e.g., AWS S3 or Google Firebase) for remote monitoring.
*   **Stealth Mode:** functionality to completely hide the application window and run silently in the system tray or background process.
*   **Email Alerts:** valid use cases (like personal laptop recovery), send automated email notifications when specific keywords are detected.
*   **Advanced Encryption:** Upgrade from simple Base64 encoding to AES-256 standard encryption for robust data security.
*   **Behavioral Statistics:** Add a dashboard to analyze typing speed, active hours, and most frequently used applications.

## Slide 11: Conclusion
**Title:** Conclusion

*   **Summary:** The CyberLogger project successfully demonstrates the core concepts of input monitoring and data handling in a Python environment.
